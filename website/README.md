# byenull website

The documentation website for [byenull](../README.md), built with [rspress](https://rspress.rs/).

## Running locally

The website's code samples are type-checked with [twoslash](https://twoslash.netlify.app/) against the real packages, and its API reference is generated from source with [typedoc](https://typedoc.org/) at build time. Build the packages first, then start the dev server:

```bash
pnpm install
pnpm --filter byenull --filter byenull-testing build
pnpm --dir website dev
```

For a production build and local preview:

```bash
pnpm --dir website build
pnpm --dir website preview
```

## Structure

- `docs/guide/start` — Getting Started
- `docs/guide/tutorial` — Tutorial (Basics → Transforming → Resolving)
- `docs/guide/how-to` — How-To Guides
- `docs/guide/explanation` — Explanation
- `docs/api` — API reference, generated by the typedoc plugin in `plugins/typedoc` (never edited by hand; regenerated on every dev/build run)
