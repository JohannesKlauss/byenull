# byenull website

The documentation website for [byenull](../README.md), built with [rspress](https://rspress.rs/).

## Running locally

[Twoslash](https://twoslash.netlify.app/) type-checks the website's code samples against the workspace packages. The [TypeDoc](https://typedoc.org/) plugin generates the API reference from source during development and build runs. Build the packages first, then start the dev server:

```bash
pnpm install
pnpm --filter byenull --filter byenull-testing build
pnpm --dir website dev
```

For a production build and local preview:

```bash
pnpm --dir website build
pnpm --dir website preview
```

## Structure

- `docs/guide/start` contains introductory guides.
- `docs/guide/tutorial` contains tutorials on basics, transforming Option values, and resolving Option values.
- `docs/guide/how-to` contains task-focused guides.
- `docs/guide/explanation` discusses the library's design.
- `docs/api` contains the API reference generated by the TypeDoc plugin in `plugins/typedoc`. Do not edit these files by hand because development and build runs regenerate them.
